# VoicePrompter

VoicePrompter es una web app de teleprompter con desplazamiento por voz, funcionamiento offline como PWA y procesamiento local en el navegador.

## Características

- Desplazamiento por voz
- Detección automática de idioma
- Modo espejo
- Grabación de video integrada
- Historial local de guiones
- Personalización de tipografía, colores y espaciado
- Soporte offline como PWA

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite
- TypeScript
- Tailwind CSS
- vite-plugin-pwa
